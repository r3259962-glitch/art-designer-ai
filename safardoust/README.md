# سفر‌دوست

نسخه رایگان سایت سفر‌دوست؛ یک شبکه برای آشنایی مسافران و افراد محلی.

## معماری

- Frontend: HTML/CSS/JavaScript
- Hosting: GitHub Pages
- Backend/Database/Auth/Storage: Supabase Free
- اطلاعات تماس خصوصی در جدول `private_contacts` نگهداری می‌شود.
- کلید `service_role` هرگز نباید در مرورگر قرار بگیرد.

## راه‌اندازی Supabase

1. یک پروژه رایگان در Supabase بسازید.
2. محتوای `supabase-schema.sql` را در SQL Editor اجرا کنید.
3. مقدار Project URL و کلید anon/publishable را در `supabase-config.js` قرار دهید.
4. در Authentication، روش Email را فعال کنید.
5. سپس سایت را از GitHub Pages منتشر کنید.

## وضعیت فعلی

رابط کاربری و مدل داده آماده است. فرم پروفایل حداقل یک راه ارتباطی می‌خواهد؛ شماره تلفن اختیاری است. اطلاعات تماس عمومی نمایش داده نمی‌شود.

## مرحله بعد

اتصال واقعی Authentication، پروفایل‌ها، درخواست دوستی، پیام‌رسانی و Storage عکس‌ها باید با URL و کلید پروژه Supabase فعال شود.

## وضعیت اتصال (اکتبر ۲۰۲۶)
- رابط سایت به پروژه Supabase متصل شده است؛ کلید موجود در `supabase-config.js` از نوع publishable و مناسب مرورگر است. کلید `service_role` را هرگز در فایل‌های عمومی قرار ندهید.
- ورود و ثبت‌نام ایمیلی، ذخیره پروفایل عمومی، جست‌وجوی پروفایل‌های واقعی، و نگهداری جداگانه اطلاعات تماس خصوصی در کد پیاده‌سازی شده‌اند.
- برای تأیید ایمیل، در Supabase بخش **Authentication → URL Configuration**، آدرس سایت را در **Redirect URLs** اضافه کنید. اگر GitHub Pages فعال باشد، آدرس می‌تواند `https://r3259962-glitch.github.io/art-designer-ai/safardoust/` باشد؛ ابتدا فعال بودن Pages را بررسی کنید.
- پروفایل‌های نمایشی ساختگی حذف شده‌اند؛ تا وقتی اعضای واقعی ثبت‌نام نکنند، فهرست خالی است.
- درخواست دوستی از رابط پروفایل ثبت می‌شود؛ صندوق درخواست‌ها، پذیرفتن/رد کردن، و گفت‌وگوی خصوصی پس از پذیرفته‌شدن دوستی پیاده‌سازی شده‌اند. سیاست امنیتی دیتابیس نیز ارسال پیام را به دوستان پذیرفته‌شده محدود می‌کند.
- پنل مدیریت کاربران و گزارش تخلف هنوز ساخته نشده‌اند؛ این بخش در مرحله بعدی است.
