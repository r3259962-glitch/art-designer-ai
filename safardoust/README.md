# سفر‌دوست
نسخه رایگان سایت سفر‌دوست.

## انتشار رایگان
GitHub Pages برای فایل‌های HTML/CSS/JS مناسب است. این پوشه را می‌توان به عنوان سایت پروژه منتشر کرد.

## بک‌اند رایگان
برای حساب کاربری، دیتابیس، پیام‌ها و تصاویر، Supabase Free در نظر گرفته شده است. فایل `supabase-schema.sql` جداول و RLS اولیه را دارد.

## وضعیت
رابط سایت و ساختار داده آماده‌اند؛ اتصال واقعی Supabase نیازمند URL و anon key پروژه Supabase است و نباید کلید service_role در مرورگر قرار گیرد.
